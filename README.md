# Zero Parades skill

An agent skill that answers ZERO PARADES: For Dead Spies questions from https://zeroparadesdb.com: skills, thoughts, items, characters, tasks, places, skill checks, dialogue and build planner links, in five languages, with the page link of every record it uses.

Install by copying this directory into the agent's skills directory (for Claude Code, `~/.claude/skills/zero-parades/`). It needs Node.js 20 or later. [SKILL.md](SKILL.md) holds the instructions and commands.
